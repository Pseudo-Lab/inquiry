# ADR-D2 — 그래프 모델

- 상태: **Proposed**
- 작성일: 2026-08-28
- 관련: PRODUCT-CONCEPT §6.2 §21.3 · REVIEW 1-②

## 맥락

원문 §6.2는 내부 구조를 "DAG 또는 제한적 순환을 허용하는 Inquiry Graph"로 열어뒀다. 순환 허용은 표현력을 높이지만 하위 기능 난이도를 급격히 올린다.

## 결정

**MVP(M2~M3)는 DAG-only. 순환은 M5(확장) 이후 재검토.**

## 근거

순환을 허용하면 아래가 전부 훨씬 어려워진다.

- staleness / drift 전파(§12)
- "중심선과의 거리 = 개념적 차이" 시각 지표(§9)
- synthesis 계보 추적(§6.3)

DAG로도 원문의 핵심 경험(분기·재결합·synthesis)은 표현 가능(synthesis = 다부모 노드).

## 결과 · 트레이드오프

- 사이클을 만들려는 연산은 생성 시점에 거부하거나 새 노드로 우회.
- "분기 후 재결합"은 다부모 DAG로 충분히 표현.
- 순환이 실제로 필요한 사용 사례가 M3 이후 관측되면 그때 제한적 순환을 도입.

## 대안 (기각/보류)

- **제한적 순환 즉시 허용:** 표현력↑이나 레이아웃·전파·계보 전반의 복잡도가 MVP 단계에서 감당 불가 → 보류.

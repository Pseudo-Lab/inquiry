# Pivot to monitor/control-plane — Phase 0–1

> 전략 전환([ADR-D12](../../decisions/ADR-D12-monitor-control-plane.md)) 구현 계획. inquiry = 공유 탐구 그래프 + MCP 인제스천 + 멀티에이전트 모니터. 외부 harness 에이전트가 가설을 생성, inquiry는 수용·모니터.

**선행 결정 (사용자 확정 2026-10-12):** 모니터/control-plane 전환 · MCP 인제스천 · 공유 그래프(에이전트=`agent:<name>`) · self-run(openai_adapter·Runner·spend-cap)은 optional 보존 · 세션/pane은 orca.

## Phase 0 — 문서 (전략 기록) ✅ (2026-10-12)

- MILESTONES §M3에 피벗 노트 + "근거 기반 가설 제안" 재프레이밍(리서치 커넥터=harness).

## Phase 1 — MCP 인제스천 + 모니터 MVP ✅ (2026-10-12)
- `features/ingest/service.py` `IngestService(root, agent)`: `add_hypothesis`·`add_evidence`를 **`agent:<name>` actor로 커밋**(이벤트 소싱 코어 재사용, 임의 세션명 허용·`:`금지). 인콰이어리는 사람이 부트스트랩 전제.
- `monitor.py` `summary(events, state)`: 상태별 가설 수·기여 agent·saturation(D11)·near-duplicates·최근 활동. 순수.
- `mcp_server.py`: `add_hypothesis`/`add_evidence`/`status` 핸들러(dep-free, 테스트됨) + `serve()`(lazy `mcp` import, 미설치 시 명확한 안내). FastMCP tool 3종.
- `ui/cli.py`: `inquiry status`(모니터 JSON) + `inquiry mcp --agent <name>`(서버 실행).
- **검증:** `tests/test_ingest_monitor.py`(8)·`test_mcp_and_status.py`(6). 전체 155 그린. CLI 스모크: status 동작, mcp 미설치 시 안내. 두 에이전트가 한 그래프에 기여 + 교차 near-duplicate 확인.

**아키텍처 payoff:** 사람-에이전트 분업이 D5(_AGENT_EDGES)+D10(actor)로 이미 강제 — 에이전트는 제안/탐색만, 사람이 터미널 결정 확정. 코어 변경 0, 추가만.

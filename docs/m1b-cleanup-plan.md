# 선택한 Git-log 버전 정리

사용자 결정: 박스·고정 열이 있는 세로형 브랜치 시나리오만 남긴다.

1. 기존 17개 테스트와 선택 버전의 3상황×3폭×plain/color 출력 해시를 보존한다.
2. 이전 layout.py/candidates.py에 묶여 있던 필요한 셀 폭·상태·색 함수를 presentation.py로 그대로 분리한다. branch_scenarios.py의 출력과 CLI는 유지한다.
3. 기존 A/B/C 및 초기 D 소스·전용 테스트·이미지·비교 문서를 .omx/archive 아래 유일한 보관 폴더로 이동한다. 최종 scenarios 이미지·preview 도구·M1a 파일은 남긴다.
4. 최종 README와 마일스톤·결과 문서를 선택안 기준으로 정리한다. 100노드/전체 매트릭스까지 선택안에 구현됐다는 오해를 남기지 않는다.
5. 남은 테스트와 18개 출력 해시를 확인한다. 새 의존성이나 새 디자인은 추가하지 않는다.

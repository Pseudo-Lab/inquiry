# 세로형 브랜치 상황 확장

사용자 요청: 이어지는 브랜치, 재분화, 합류, reject/종료를 보여주는 추가 디자인.

최종 사용자 선택에 따라 다른 시안은 보관하고 `branch_scenarios.py`의 박스형 Git-log 버전만 유지한다. 세 가지 수동 배치 fixture를 제공한다.
1. Continue & fork: 주계보와 지지 가지가 이어지고 그 가지에서 대안 가지가 다시 갈라진다.
2. Merge & continue: 두 부모에서 새 SYN 노드로 합류하고 그 뒤 탐색이 이어진다. 입력 노드는 synthesized, 새 노드는 exploring으로 구별한다.
3. Refuted & closed: 반박과 사람 종료를 다른 기호·텍스트로 표시한다. 잘린 가지와 살아 있는 주계보, 종료 이유·근거 스냅샷·재검토 조건을 표시한다.

ADR-D2의 비순환·다부모 합류와 ADR-D5의 refuted/human-closed 구별을 따른다. 상태 전이 엔진, 실제 근거, Git 연동, 조작 기능을 구현하지 않는다. 사용자에게 전달할 이미지는 같은 컬러와 셀 그리드로 만든다.

검증: 각 시나리오 80/100/120열, 텍스트/ANSI 동등성·유효 부모·비순환·합류 부모2개·잘린 가지의 후손 없음, 이미지에서 연결선을 직접 확인한다. 선택 전 M1b 정본이나 MVP 범위는 바꾸지 않는다.
